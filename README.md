# MainahtunesTeam Website

A Next.js 14 / TypeScript agency portfolio for MainahtunesTeam.

## Included pages
- `/` — homepage
- `/about` — agency and founder information
- `/services` — complete 24-service catalog grouped into six disciplines
- `/services/[slug]` — an individual, statically generated detail page for each service
- `/visuals` — visual portfolio showcase
- `/contact` — project enquiry form

## Run locally
```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build for production
```bash
npm run build
npm start
```

Before launch, replace placeholder contact/social details with verified agency details and connect the enquiry form to a form delivery provider. Service descriptions intentionally avoid guarantees for third-party outcomes such as playlist placements, radio airplay, Google Knowledge Panels and YouTube monetization.
